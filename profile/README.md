## 🧠 Overview

Soundpad is a Windows soundboard application that lets users play audio clips through their microphone in voice chats, games, and other applications. It combines sound playback and microphone output in one interface, making it easy to trigger effects, music snippets, memes, and custom recordings while communicating.

The program includes tools for organizing audio collections, assigning keyboard shortcuts, adjusting playback levels, and recording sounds directly into the library. Its integration with supported voice applications makes it useful for gaming sessions, online conversations, and content creation.

## Additional Information for Windows Users

Soundpad works alongside Windows audio devices and supported communication applications, allowing users to play sound effects without switching away from their current activity. For consistent results, select the appropriate recording and playback devices in Windows and check that the target voice application is using the intended microphone.

The program is particularly useful when you want quick access to frequently used clips. Creating clear names for audio files and assigning memorable hotkeys can make it easier to trigger the right sound during gameplay or conversations.

Audio routing and microphone processing can vary depending on the device, driver, and application configuration. If other participants cannot hear playback, review the selected input device, Windows sound settings, and the voice application's microphone configuration.
